# Job Mate – Job Portal

Job Mate is a full-stack job portal developed using the MERN stack. 
It provides separate functionalities for students/job seekers and recruiters,
allowing students to explore and apply for jobs while recruiters can post
and manage job opportunities and applications.

## Features

### Student
- User registration and login
- Browse and search job opportunities
- Apply for jobs
- Track application status
- Manage profile

### Recruiter
- Recruiter registration and login
- Post job opportunities
- Edit and delete job postings
- View applicants
- Manage job applications

### Other
- Role-based authentication and authorization
- Responsive user interface
- Resume/profile document upload
- State management using Redux
- MongoDB database integration

## Tech Stack
